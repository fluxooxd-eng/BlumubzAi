CARA DEPLOY
1. Upload semua isi folder ini ke repo GitHub baru.
2. vercel.com -> Add New -> Project -> import repo -> Deploy.
3. Settings -> Environment Variables, isi:
   SKY_VERIFY_URL  (endpoint verifikasi dari dashboard SkyKeySystem)
   SKY_API_KEY     (API key/secret dari dashboard SkyKeySystem)
4. Redeploy.
Tombol "Dapatkan Key" mengarah ke https://sky-development-kohl.vercel.app/dashboard
